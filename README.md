# Personal Portfolio Website

A responsive, lightweight personal portfolio website built to showcase my web development projects, technical skills, and professional background. 

🌐 **Live Demo:** [My Portfolio](https://ahnafobaid.github.io/)

---

## 🚀 Features

- **Semantic HTML:** Structured using clean, modern HTML5 elements for optimal SEO and structure.
- **Responsive Layout:** Built with a mobile-first approach using CSS Flexbox/Grid to look great on all screen sizes.
- **Project Showcase:** An interactive gallery highlighting my featured web development projects.
- **Contact Integration:** A functional contact form for direct inquiries from clients and recruiters.

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Styling:** CSS3
- **Hosting:** GitHub Pages
